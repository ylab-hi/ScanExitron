# Quick Start

Get started with ScanExitron in under 5 minutes! This tutorial will guide you through running your first exitron calling analysis.

!!! info "What you'll learn"
    - How to run ScanExitron calling on a BAM file
    - Understanding the exitron calling output
    - Converting the exitron calling output to VCF format

    **Time**: ~5 minutes

## Prerequisites

- ScanExitron installed ([Installation Guide](installation.md))
- A reference genome FASTA file (e.g., `hg38.fa`)
- A gene annotation GTF file (e.g., `gencode.v37.annotation.gtf`)
- A BAM file to analyze (we'll use the sample BAM file in the repository)

## Step 1: Locate the Sample Data

ScanExitron includes a small test BAM dataset in the repository under the `tests/` directory:

- `tests/test.bam` (with its index `tests/test.bam.bai`)

If you cloned the source directory, they are already available. Otherwise, you can download them from GitHub:

```bash
# Download sample files
wget https://github.com/ylab-hi/ScanExitron/raw/main/tests/test.bam
wget https://github.com/ylab-hi/ScanExitron/raw/main/tests/test.bam.bai
```

## Step 2: Run Splicing Calling

Run exitron calling using `scanexitron run` by pointing it to your reference FASTA (`-r`), annotation GTF (`-g`), and the input BAM (`-i`):

```bash
scanexitron run -i test.bam -r hg38.fa -g gencode.v37.annotation.gtf -o test
```

!!! note "Outputs generated"
    This will produce the exitron calling output:
    
    1. **`test.exitron`**: A tab-separated file listing all identified exitron splicing events.
    2. **`test.hq.janno`**: An intermediate annotated junction file generated by `regtools` for manual review.

## Step 3: Understand the Output File

The output `test.exitron` is a tab-separated file. Let's look at the generated fields:

| Column | Description |
| :--- | :--- |
| **`chrom`** | Chromosome where the exitron is located |
| **`start`** | 0-based start position of the exitron |
| **`end`** | 0-based end position of the exitron |
| **`name`** | Junction identifier |
| **`ao`** | Number of supporting junction-spanning reads |
| **`strand`** | Splicing strand (`+` or `-`) |
| **`gene_symbol`** | HGNC gene symbol |
| **`length`** | Exitron length in base pairs |
| **`splice_site`** | Splice site dinucleotides (e.g., `GT-AG`) |
| **`gene_id`** | Ensembl/Gencode gene ID |
| **`pso`** | Percent Spliced Out (relative exitron abundance) |
| **`psi`** | Percent Spliced In |
| **`dp`** | Local sequencing coverage depth |
| **`total_junctions`** | Total junction-spanning reads in the sample |

Here is an example output:

```text
chrom	start	end	name	ao	strand	gene_symbol	length	splice_site	gene_id	pso	psi	dp	total_junctions
chr17	50071324	50071418	JUNC00000010	16	+	ITGA3	93	GT-AG	ENSG00000005884.18	0.0267	0.9733	598	104499
chr17	58302312	58302408	JUNC00000893	3	-	TSPOAP1	95	GT-AG	ENSG00000005379.17	0.0337	0.9663	89	104499
```

## Step 4: Convert to VCF

Convert the calling output into a standard VCF file using `scanexitron convert`:

```bash
scanexitron convert -i test.exitron -r hg38.fa -o test.vcf
```

This generates `test.vcf` which can be used in downstream annotation engines (such as VEP or Annovar) to evaluate functional impacts (e.g., frame shifts, amino acid deletions).

!!! success "Congratulations!"
    You've successfully completed the quick start! You are now ready to run ScanExitron on your own datasets.
